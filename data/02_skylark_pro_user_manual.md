# Skylark Pro — User Manual (excerpt)

Document version: 4.2 · Applies to hardware revision C and firmware 2.x

## 1. In the box
- Outdoor sensor array (anemometer, wind vane, rain gauge, thermo-hygrometer, UV sensor)
- Indoor display hub with barometer
- Mounting pole bracket and 4 stainless steel hose clamps
- USB-C power adapter (5 V / 2 A) for the hub
- 4 × AA lithium batteries for the outdoor array

## 2. Placement guidelines
- Mount the outdoor array at least **1.5 m above ground** and away from walls, roofs and paved surfaces, which radiate heat.
- For accurate wind readings, the anemometer should ideally be **2 m above any obstacle within 10 m**.
- The array's arrow marked "N" must point to true north. The hub can correct an offset of up to 30° in Settings → Calibration → Wind.
- Maximum wireless range between array and hub: **150 m in open air**, typically 60–80 m through two walls.

## 3. Pairing
1. Insert batteries into the outdoor array. The status LED blinks green.
2. Power on the hub. Press and hold **SYNC** for 5 seconds.
3. Pairing completes within 3 minutes. If the LED turns solid red, see Troubleshooting.

## 4. Specifications

| Measurement | Range | Accuracy |
|---|---|---|
| Outdoor temperature | −40 °C to +65 °C | ±0.3 °C |
| Humidity | 1–99% RH | ±3% RH |
| Pressure | 540–1100 hPa | ±1.0 hPa |
| Wind speed | 0–50 m/s | ±1 m/s or 5% (whichever is greater) |
| Rainfall | 0–9999 mm | ±4% |
| UV index | 0–16 | ±1 |

Update interval: 16 seconds (wind), 60 seconds (all other sensors).
Battery life, outdoor array: approximately **18 months** with lithium AA cells. Alkaline cells are not recommended below −10 °C.

## 5. Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| Solid red LED on array | Pairing timeout | Remove batteries for 30 s, then repeat pairing |
| Rain total stuck at 0 | Debris in tipping bucket | Remove the funnel cap and clean the bucket |
| Wind direction always "N" | Wind vane magnet loose | Contact support; covered by warranty |
| Hub shows "--" for outdoor data | Signal lost for >10 min | Move hub closer or add a Skylark Repeater |

## 6. Maintenance
- Clean the rain funnel every 3 months, or monthly in autumn.
- Clean the UV sensor dome with a soft dry cloth. Never use alcohol-based cleaners.
- Recalibrate the barometer to local sea-level pressure after moving the hub to a new location.
