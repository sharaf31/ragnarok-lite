# Skylark Cloud — Frequently Asked Questions

**Q: How much does Skylark Cloud cost?**
A: There are two plans.
- **Basic** (free): 30 days of history, 3 alerts, no API access.
- **Plus**: EUR 3.99 per month or EUR 39 per year. Unlimited history, unlimited alerts, frost warnings, and API access (1,000 requests per day).
Schools and registered non-profits get Plus free on request.

**Q: Where is my data stored?**
A: All customer data is stored in EU data centres (Frankfurt primary, Amsterdam backup). Norvik does not sell personal data. Anonymised weather readings may be contributed to the Open Hyperlocal Weather dataset only if you opt in under Settings → Privacy.

**Q: Can I export my data?**
A: Yes. Plus subscribers can export any date range as CSV or JSON from the web dashboard. Basic users can export the last 30 days as CSV.

**Q: What happens to my data if I cancel Plus?**
A: Your account returns to Basic. History older than 30 days is kept for 90 days in case you resubscribe, then permanently deleted.

**Q: Does Skylark Mini work with Skylark Cloud?**
A: Yes, but frost warnings need a pressure sensor and are only available on Skylark Pro and Pro+.

**Q: What is the API rate limit?**
A: 1,000 requests per day on Plus. Higher limits for research and agricultural partners are available on request through partners@norvik.example.

**Q: Does the hub keep working without the internet?**
A: Yes. The hub shows live readings without an internet connection and buffers data locally, then uploads it when the connection returns. See the latest firmware release notes for the current buffer length.

**Q: Is there a smart-home integration?**
A: Home Assistant (official integration since 2025) and Apple HomeKit via the Skylark Bridge accessory. Google Home is not supported yet.
